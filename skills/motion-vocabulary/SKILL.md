## Operation and feature contract

Core frame arithmetic and specification authoring require no media adapter. Optional demonstration uses `scene.frame@1` with `timing.frame_seek` and `inspection.visual@1`; do not block the written vocabulary if that optional binding is absent.

## Role procedure

1. List the attention tasks, not a menu of effects. For compare, keep marks aligned and move a shared focus bracket; for reveal, uncover information in reading order; for emphasize, use one bounded accent that settles back to baseline.

2. For each move specify the affected property, stable endpoints, frame duration, delay, direction and easing intent. State whether overshoot is forbidden; avoid treating an easing adjective as an executable curve definition.

3. Set a competition budget: one primary move per focal beat, supporting movement only if it does not interrupt reading. Declare which layers remain still and how repeated uses preserve direction and duration.

4. Provide a reduced-motion substitution for every chosen move, such as an immediate state change with a readable hold rather than zoom or large travel. Hand the small selected set to motion-studio:motion-primitives; leave sequence scheduling to motion-studio:timeline-author.

## Outputs and evidence

- Small motion specification of intent, easing, direction and reusable examples.

Return an intent-to-primitive table with normal/reduced-motion variants, endpoints and constraints. A written selection is complete as guidance only; optional rendered examples must be labelled separately from unrendered examples.
