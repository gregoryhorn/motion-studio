# Dimensional titles

## When to use

Produce readable dimensional typography sequences. Exclude generic 3D object rendering or compulsory 3D software.

## Inputs and retained outputs

Required: Approved title text, font source facts when supplied, depth/material direction and reading duration.

Produce: Editable title source, actual sequence and readability/frame evidence. Attach each output to its current
project and applicable scene/asset revision; retain editable source and actual
bytes, not only a screenshot, URL or completion message.

## Authority and execution boundary

Follow the shared production instructions in `motion-studio:studio-produce`
before this specialist procedure; load that qualified skill, not a relative
cross-skill file link. Resolve current project/scene/asset IDs, expected revision,
input hashes and selected binding from actual tools. Preserve supplied provenance/
attribution facts without demanding rights clearance. Unknown or restricted rights
and absent licenses do not block production, release or packaging. Work only on declared
task-owned candidates; preserve immutable sources and approved outputs. Changes
invalidate only affected descendants. Record binding/version, job/attempt, input
and output hashes and inspected frame/sample coverage in the project.

This is independently authored guidance, not a qualified runtime route. Linux
identifies the authoring host only; adapter/platform production support is not
established. Use only advertised public actions and schemas. Missing engines,
`NOT_IMPLEMENTED`, absent actions or unsatisfied required features mean blocked:
name the operation/feature and smallest remedy, preserve existing artifacts and
return the gap. Do not fabricate media, timing, receipts or acceptance. Do not
install dependencies/models, modify configuration, upload, spend or substitute a

native source, not a promise of lossless translation.

## Required and conditional capabilities

Require `scene.author@1`, `scene.render@1`, `scene.frame@1` with
`timing.frame_seek`, `inspection.visual@1` and `inspection.playback@1`.
Use `scene.3d` for a physical title, or an explicitly registered dimensional
feature/schema on the selected compatible renderer; generic 2D support is not
proof of extrusion. Require declared font/layout support and `text.shaping` when
needed by the title. Probe actual sequence output with `media.probe@1`.

## Procedure

1. Freeze the exact approved title including accents, punctuation and line
   breaks, font source facts when supplied, reading duration, depth/material direction and frame range.
   Test supplied glyphs and shaping in the chosen binding. Missing glyphs block
   the affected title or require an approved font revision, never missing squares.
2. Author editable type controls, depth/bevel or supported dimensional treatment,
   camera and lights. Keep the text source and font/dependency references even
   when approved geometry conversion is needed. This role optimizes typography,
   not an unrelated 3D object showcase.
3. Allocate entrance, readable hold and exit at explicit frames. Judge the whole
   title at delivery size; depth, rotations, highlights and perspective must not
   obscure letterforms during the hold. Preserve intended text rather than shorten
   it without approval to solve a layout issue.
4. Evaluate entrance/hold/exit samples and render the bounded sequence. Inspect
   accents, counters, bevel intersections, edge aliasing and light contrast. Watch
   actual playback to establish hold duration and ease; a static beauty frame
   cannot prove the title was readable in motion.
5. Return editable title source, collected sequence and exact inspected frames/
   playback coverage. Revise only title and dependent outputs. If dimensional
   support is absent, report it; propose a flat title only as an explicit changed
   treatment, not as successful dimensional output.

## Verification

**SK-S58-output (future empirical acceptance, not yet passed):** A supplied accented title remains correctly shaped and readable at its hold; unavailable glyphs block or disclose a revised font choice rather than rendering missing squares.


## Pitfalls and handback

Report actual artifacts separately from intended outputs and unresolved gaps.
Retain failed/partial jobs and any prior approved version. Compilation, selecting
a binding, source inspection and this authoring test are not production evidence;
a newly rendered preview is an execution job. Submit only a frozen authorized
plan, reconcile uncertain effects before any retry, and use normal host approval
for typed handoffs. Return the current revisions and real artifact handles to
`motion-studio:studio-produce`; candidate encode, decode/measurement, frame/audio/
playback review and exact-byte promotion remain required when applicable. Never
turn specialist judgement into user approval or mark a route exercised from mocks.
