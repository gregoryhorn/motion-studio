# Shared production contract

Independent B02 guidance derived from build contracts, not old-pack prompts.
This reference owns common state, authority and evidence rules; role skills own
their creative procedure. Use only the live tool's advertised schema. Planned
contracts are not proof that an action is implemented. An unavailable action or
NOT_IMPLEMENTED response is a stopping boundary, never permission to fake state.

## Source facts, not rights clearance

Use/redistribution-rights clearance is not a production, release, promotion or
package prerequisite. Unknown/restricted rights and absent licenses must not
block these operations or prompt demands for a license or permission statement.
Retain truthful source provenance, supplied attribution/license facts and unknowns;
never relabel them as cleared or invent grants. Historical license/frontmatter
metadata is unchanged. Execution, data transfer, spend, privacy/identity consent
and host approvals still apply, as do all creative, technical, art, audio and
delivery-profile quality gates. This policy grants no external legal rights.

## State and authority

- Resolve IDs and the current project/document/job revision through native tools.
  Pin input hashes and expected revisions for changes. A stale write requires
  rereading and reconciling intent, not overwriting newer work.
- Brief, brand, timeline and corrections remain authoritative project documents.
  Keep immutable originals, approved bytes and unaffected dependencies. Invalidate
  only actual descendants. A new adapter may require newly authored source; retain
  old sources and never promise lossless native-source translation.
- No hidden fallback: capability, credential, execution/data/privacy authority or budget gaps name the exact
  blocked requirement. An alternative stays a proposal until binding, plan and
  changed effects are authorized. Unknown cost is not free. Rights uncertainty is not a plugin prerequisite.
- Discovery, selection, open, existing-preview viewing and plan compilation never
  execute. Rendering a new preview is a job. Do not install, start a model,
  download, generate, upload or buy anything merely to discover compatibility.
- Use the host approval and credential surfaces. Never embed credentials, import
  private handlers or invent a universal dispatcher. Claim a typed handoff before
  invoking the exact native tool; reconcile uncertain effects instead of retrying.
- Status is observation; collect validates known results without launching new
  work. A live worker can continue its already authorized plan; after worker loss
  any new submission needs explicit authority, not collect-as-resume.

## Operation and feature binding

The catalog stores semantic per-role requirements and a canonical crosswalk.
These are requirements, not invented public action/ABI names. Plans must resolve
concrete registered operation IDs, schemas, ports, features and selected adapters.
Core decisions, arithmetic and project changes need no media adapter. Do not
require every operation below for every journey.

| Work actually requested | Binding requirements |
|---|---|
| Probe or full decode | media.probe@1, full_decode true when required |
| Author/render/frame inspection | scene.author@1, scene.render@1, scene.frame@1 as needed; scene.2d/3d/raster/vector and timing.frame_seek/frame_exact only where required |
| Transcribe/align/synthesize | speech.transcribe@1, speech.align@1, speech.synthesize@1 as needed; speech.words versus speech.segments is explicit, never guessed |
| Caption layout/burn/sidecar | caption.layout@1, caption.render@1, caption.export@1 as requested, all pinned to the same CaptionPlacement and style |
| Word highlights or shaped text | caption.word_highlight plus actual word timing; text.rtl/text.shaping when requested, verified fonts and actual output glyphs |
| Assembly or transforms | edit.assemble@1, media.transform@1 with explicit conversions only |
| Mix/measurement | audio.mix@1, audio.measure@1; audio.sample_exact where required |
| Final delivery | delivery.encode@1, review.check@1, delivery.package@1 as requested, plus actual probe/decode |
| Judgement | inspection.visual@1, inspection.audio@1 when audio exists, inspection.playback@1; record actual coverage |

Specialized alpha, temporal matte, vector player, 3D and effect features require
exact compatible declarations. A generic renderer flag does not imply support.
Missing optional features do not become blockers for independent valid targets.
Speech captions require actual audio/timings; source-relative caption exports do
not satisfy delivery-sidecar timing. Silence is valid, not failed transcription.

## Evidence and preservation

Candidate encode precedes decode/measurement/frame/audio/playback review. Review
receipts bind exact candidate/dependency/sidecar hashes, revisions and actual
coverage. A source preview is not final encoded-media evidence. Keep technical
checks, agent judgement and user acceptance distinct. Never record deterministic
results as invented user decisions or claim unseen intervals were inspected.

Promote only exact checked bytes with current required gates and no unresolved
blocking findings; stale evidence refuses promotion and leaves masters intact.
Package only actual requested masters/sidecars/source closure. Verify reconstruction
before calling a package reconstructable. Return real supported file handles,
not guessed paths, URLs or MEDIA references. Partial delivery lists completed,
blocked and unrequested variants separately. Cleanup covers owned temporary work
only and never destroys approved artifacts or unrelated resources.
