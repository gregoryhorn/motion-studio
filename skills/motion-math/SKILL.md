## Operation and feature contract

Core approved calculation tools for math/checks, not mental arithmetic; no media adapter for parameter artifacts. Optional applied example uses `scene.frame@1` with `timing.frame_seek` and `inspection.visual@1`.

## Role procedure

1. Define domain/range units, frame/sample conventions, endpoint inclusion and error policy. Specify whether each mapping clamps, wraps or extrapolates; a zero-width domain must explicitly error or use a declared constant policy.

2. Calculate mapping and easing parameters with tools. For 0..100 to 20..80, evaluate both endpoints, an interior point and outside-domain inputs, then independently check monotonicity and boundedness.

3. Define seeded variation from stable object identity and a retained seed/algorithm version. Avoid evaluation-order-dependent random streams; repeat the same request and compare actual calculated placements.

4. Check bounds and spacing in parameter space, then inspect an applied rendered example for label collisions if a renderer is available. Numerical separation alone does not prove glyph bounds remain clear.

## Outputs and evidence

- Calculated parameter artifact, independent checks and demonstrative frame samples.

Return units, formulas, actual tool-produced parameter values, independent checks and seed provenance. State when the demonstrative frame is pending, without discarding valid calculations or claiming visual clearance.
